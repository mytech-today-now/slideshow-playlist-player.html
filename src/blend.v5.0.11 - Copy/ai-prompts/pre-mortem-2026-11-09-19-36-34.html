Failure mode
When Playlist order or Slideshow order is Random and that layer is the experience end target, the layer never reports done. Stop, Loop, and Go to Next Experience therefore never run for an otherwise valid show. A DJ or venue operator can set end target to Playlist, order to Random, and playback mode to Stop, then watch the show continue until someone stops it manually.
Evidence or rationale
In playback-mode.js, selectNextLayerIndex handles random mode by choosing among alternatives and always returning an index when playableIndices is non-empty (approximately lines 62-67). There is no visited-set or wrap=false terminal path for random mode. In app.js, advancePlaylist (approximately lines 9071-9089) and advanceSlideshow (approximately lines 9120-9138) take that random result and call play with allowWrap true. They set layerCompletionState.playlistDone or slideshowDone to false and return without calling markLayerComplete. markLayerComplete and maybeHandleExperienceCompletion (approximately lines 8320-8338) only complete the experience when the selected end target is done (or the companion layer is done if the target has no playable items). handleExperienceCompletion (approximately lines 8420-8446) implements Loop, Next, and Stop. index.html exposes all three controls together (approximately lines 273-299) with no note that Random prevents ending. tests/e2e/experience-end-target.e2e.spec.mjs persists random order (approximately lines 88-147) and tests sequential stop behavior (approximately lines 150-211) but does not cover random completion. This is confirmed application code behavior, not a testable assumption.
Why this matters
Experience end targets were just added (CHANGELOG Unreleased; cache version 20261101-v5.0.11-experience-end-target) so venue shows can stop or advance at a chosen layer boundary. Random is a first-class order mode. Leaving Random without a cycle end makes the new feature fail for a common live-playback configuration and trains operators to distrust Stop and Next Experience.
Recommended mitigation
Define a cycle-complete rule for random order, return a terminal signal from the pure helper, call markLayerComplete when the cycle ends, add regression and e2e coverage, and describe the rule beside the order and end-target controls. Keep sequential behavior identical.
